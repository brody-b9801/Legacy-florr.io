# Legacy florr.io
 
A local, offline copy of the old florr.io client (`static.florr.io/old/`), pulled out of a HAR capture

Completed protocol capture, working on decoding wire protocol, patching client.wasm, and (after finishing Capsule Clash) building an authoritative multi-connection server that runs one shared world and emits florr-protocol packets the client accepts, which I can self-host to play with friends

## Note 
Game assets belong to their original owner, M28. This is purely a fan project. Since this version of the game, florr.io has change drastically. However, I spent hours on this version of the game with my friends and is honestly nostalgic to me. This is solely being built to experience the nostalgia of playing this version with those friends again.
